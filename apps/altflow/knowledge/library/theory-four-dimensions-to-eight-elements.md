## 定义

只要想透四维（外显、内含、矛盾、和谐），八要素几乎可以自动推出。转化关系是：外显变身份，内含变欲望，矛盾加现实困境变问题和负价值观，和谐变前史背景，打破和谐带来动作、阻碍、结果、正价值观。

## 适用问题

- 完成了四维设计，却不知道如何落到人物小传和大纲。
- 想检查四维与八要素是否一致。
- 动笔写大纲前要一张人物底表。

## 方法

### 转化表

| 四维灵魂 | 转化逻辑 | 八要素骨架 |
|---|---|---|
| 外显 | 外显标签直接决定起点 | 身份 |
| 内含 | 内含即内心真正渴望 | 欲望 |
| 矛盾 + 现实困境 | 矛盾内化为心理扭曲，外显身份带来现实困境，主角为了在其中生存总结出错误法则 | 问题（内部 = 矛盾；外部 = 现实困境）+ 负价值观 |
| 和谐 | 解释主角为何能在矛盾中活到现在，不直接对应要素，构成前史和初始人物关系 | 人物前史 / 初始关系 |
| 打破和谐 | 某种力量打破平衡，主角为欲望开始行动 | 动作 + 阻碍 |
| 新的和谐 | 主角不再伪装，形成新的统一 | 结果 + 正价值观 |

### 填表模板（动笔写大纲前填满）

- 外显 → 身份：
- 内含 → 欲望：
- 矛盾 + 现实 → 问题 + 负价值观：
- 和谐机制 → 前史背景：
- 打破和谐的事件 →
- 动作、阻碍、结果、正价值观：

## 示例（极端人设，仅演示转化）

想成为诗人的屠夫：
- 外显：粗鲁屠夫 → 身份：杀猪匠。
- 内含：心思细腻、爱美 → 欲望：被当作雅人看待。
- 矛盾 + 困境：自卑，社会地位低、受恶霸欺负 → 问题（内：不敢展示真我；外：穷、被欺负）；负价值观：“粗人配不上高雅，还是老实杀猪吧。”
- 和谐机制：装粗鲁能少受欺负、与同行打成一片 → 前史：靠伪装在市井生存。
- 打破和谐：诗会（或类似力量）出现 → 动作：白天凶狠杀猪维持外显，晚上写诗并想参加诗会；阻碍：恶霸嘲讽（外）、怯懦（内）。
- 结果：成为全城闻名的“杀猪诗人”；正价值观：灵魂没有高低贵贱，真实的自己最有力量。

## 检查

- 外显与身份是否一致；欲望是否来自内含而非另编。
- 负价值观是否能追溯到矛盾，而不是随意设定。
- 有无“打破和谐的事件”，没有则故事启动不了。
- 结果的和谐是否是新的状态，而非回到旧的和谐。
