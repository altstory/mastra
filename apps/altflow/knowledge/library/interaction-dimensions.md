# 互动设计四维度问题清单

四个维度是诊断入口，可按项目增减；不限定题材、性别或四类主体验。

## 1. 节奏与参与窗口

玩家何时需要阅读、观察、操作、等待与休息？动作是否打断重要表演？无输入时暂停还是继续？频率依据体验测试，不使用统一每分钟或每集配额。

## 2. 动机与叙事目的

玩家为何想继续：好奇、关系、表达、掌握、协作、照料、竞争还是其他目标？可以混合或随情节变化。局部完成、平静与余韵可以收尾，不强制危机钩子。

## 3. 动作与操作方式

玩家能操作什么对象，通过选择、移动、排列、搜索、输入、节奏或协作中的哪种方式？规则如何被发现，错误、取消、重复输入如何处理？输入方式服务意义，不用几组选项代替全部互动。工具不支持的动作明确写为设计或原型需求。

## 4. 状态与反馈

如何让玩家知道动作被接收，完成了什么，有什么即时或后续影响？区分世界事实、已发生事件与角色认知。只记录需要承接的状态；表达型动作可以只改变局部体验，不必新增结局。

## 风险校验

- 承诺是否兑现：声称改变剧情却无反馈，或明明是局部表达却夸大长期影响。
- 因果是否连贯：先前动作被遗忘、未走路线事实混入合流、计划被当作已完成。
- 操作是否清楚：输入是否可发现，失败后是否可恢复，技术故障是否被误当故事结果。
- 制作是否可行：玩法是否有实现支持，成本是否符合预算，是否只做了文稿就声称完成试玩。
