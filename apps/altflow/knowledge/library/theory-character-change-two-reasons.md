## 一句话定义
人物立场一变，必须同时有**事实动机**（发生了什么逼他变）和**情绪动机**（他心里被什么压垮或打动）。转变是否合理，就看这两样。

## 适用问题
- 人物转变被读者说"太突然""不真实"。
- 要写好人变坏、坏人变好、卧底反水。
- 主角被迫作恶，怎么不丢观众。

## 方法
**检验表**
| 事实动机 | 情绪动机 | 结论 |
|---|---|---|
| 足 | 足 | 最好 |
| 不足 | 足 | 可以，情绪撑得住 |
| 足 | 无 | "转硬了"，补一场情绪戏 |
| 无 | 无 | "转崩了"，不合格，别转 |

**转变要有目的**
- 好人变坏：引发争议，把主题抬一格（是他错，还是环境和制度错）。
- 坏人变好：强化某个角色的魅力。
- 两个目的都没有，就不要转变。

**卧底在高潮反水并死去**：前期有多恶就写多恶，死时冲击才大。铺垫只提供合理性，且最好两头都能解释：揭底前它让人更恨他，揭底后又让人恍然大悟。

**主角接受对方"洗白"**：关键时刻应有怀疑，除非人设本来就偏天真。

**穿成反派（身在恶位，心仍与观众一致）**
1. 作恶的过程表里如一，恶要真，不能半途软化。
2. 作恶前后用相反的动作和台词找补：事前给自己打气，事后愧疚、发誓。
3. 让观众事先知道被害者本就可恨。
这是一致性"双刃剑"的变相用法：外在是反派，内在仍与观众站在一起。

## 示例
一名副手长期在上司手下受压，起初只是怀疑（事实），直到发现自己的名字被划掉、功劳被别人领走（情绪）才决心反水。如果只有名字被划掉的事实，没有他当晚站在雨里把旧工牌攥皱的那场戏，读者会觉得他"转硬了"。

## 检查
- 能否各用一句话写出事实理由与情绪理由？
- 缺情绪就补戏，两样都缺就删掉这次转变。
