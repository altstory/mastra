# 让两条关系线用同一问题给出不同答案

## 参考与观察

开场用场记板和扮演者建立拍摄这层现实，之后将演员在场外的关系与他们饰演的人物关系交替呈现。场景层次可辨认，两段关系得以互相照应。

## 写法

给两条线写出同一个关系问题，再给各自不同的选择条件。通过场景标题、身份称谓、工作物件或说话方式交代所在层次。将两场放在一起时，读者应能说清它们对照的是什么。

## 原创例子

年轻译员在排练中替角色念出认罪书。散场后，老师让她在真实的申诉书上签名。同一个签字动作，两场各有一名要保护的人，译员两次作出不同选择。

## 质检

读者能立刻认出这是演员还是剧中人物吗？相邻两场的对照能否改写对人物的理解？
