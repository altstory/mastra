# 互动叙事玩家心理学

## 概述

理解玩家心理是设计互动体验的关键。玩家可以通过决策、动作、观察、表达和协作参与。本页列举常见设计假设，不是所有玩家共有的心理定律；需要按实际受众验证。

---

## 核心心理需求

### 1. 代理感（Agency）

**定义**：玩家理解自己可以怎样行动，并感受到与行动相符的回应；它可以改变局部表达、理解与关系，不一定改变最终情节

**满足条件**：

- 不同的选择产生不同的后果
- 后果在合理时间内呈现
- 玩家能够预测选择的可能影响

**破坏代理感的行为**：

```
选择A → 你选择了勇敢
选择B → 你选择了谨慎
（但后续内容完全一样）
```

**增强代理感的方法**：

- 让重要行动兑现承诺；表达型互动和自然合流可以共享内容，但应有可理解的回应
- 让玩家看到选择的后果
- 允许玩家承担选择的代价

---

### 2. 预测性（Predictability）

**定义**：玩家能够大致预测选择的可能后果

**原则**：

- 选项文本应该传达后果的性质
- 不要让选项和结果完全脱节
- 隐藏的风险应该有线索提示

**好的设计**：

```
选项：直接冲进去对抗
后果：需要战斗，可能受伤（符合预期）

选项：悄悄潜入
后果：避免战斗，获得信息（符合预期）
```

**糟糕的设计**：

```
选项：直接冲进去对抗
后果：莫名其妙被困住（完全不符合预期）

选项：悄悄潜入
后果：突然触发警报（没有线索表明有陷阱）
```

---

### 3. 一致性（Consistency）

**定义**：玩家的选择在整个故事中得到尊重

**原则**：

- 承诺长期影响的重要行动应被后期承接；局部表达可以在当场完成反馈
- 不要让重要选择变得毫无意义
- 给玩家"我的选择重要"的持续反馈

**示例**：

```
第一章：选择加入阵营A
第三章：阵营A的成员来帮助你
终章：阵营A的结局对你开放
```

---

## 玩家行为模式

### 1. 最优化行为（Min-Maxing）

**定义**：玩家倾向于寻找"最佳"选择

**应对策略**：

- 不要设计明显的"最佳"选项
- 让每个选项都有代价和收益
- 多样化的成功路径

**避免**：

```
选项A：完美结果，无代价
选项B：一般结果，小代价
选项C：糟糕结果，大代价
（玩家只会选A）
```

**推荐**：

```
选项A：高风险高回报
选项B：稳健路线
选项C：低风险低回报
（各有合理性）
```

---

### 2. 收集行为（Completionism）

**定义**：玩家倾向于体验所有内容

**应对策略**：

- 设计隐藏路线供探索
- 提供"新游戏+"机制
- 让不同选择互补而非完全替代

**满足方式**：

```
"您已体验3个结局中的2个"
"还有隐藏路线未解锁：尝试在第二章找到秘密通道"
```

---

### 3. 回溯行为（Backtracking）

**定义**：部分玩家希望能回看或修正，另一些玩家享受不可逆决定；依据项目预期选择

**应对策略**：

- 明确告知哪些是关键选择
- 提供存档点
- 考虑是否允许重新选择

**设计选择**：

```
（明确提示）
【重要选择】此决定将影响后续剧情走向

（或允许存档）
在此处自动存档...

（或允许回溯）
确定选择吗？[确定] [重新考虑]
```

## 情感曲线设计

### 1. 选择焦虑（Choice Paradox）

**问题**：选项太多会让玩家焦虑

**解决方案**：

- 先以少量清楚的选择测试，数量依任务、信息组织与可读性调整
- 4个以上选项应该有清晰的分类
- 提供"跳过选择"的默认选项

**示例**：

```
不好：6个模糊的选项
好：2个清晰对立的选项 + 1个中立选项
```

---

### 2. 后悔情绪（Regret Management）

**玩家会后悔**：

- 后果超出预期
- 信息不足导致错误选择
- 看到更好的选项但无法选择

**应对策略**：

- 公平的信息提供
- 明确的风险提示
- 允许在某些情况下修正

**设计示例**：

```
"你确定要这样做吗？这可能会导致[角色]的离开。"
[确定] [再想想]
```

---

### 3. 满足感设计（Satisfaction）

**玩家满足的来源**：

- 做出了"正确"的选择
- 发现了隐藏路线
- 理解了故事的深层含义
- 看到了自己选择的长期影响

**设计方法**：

- 让每个结局都有其价值
- 是否设置明确最佳结局取决于作品承诺，不用统一价值排序代替设计
- 给"失败"赋予意义

## 常见玩家心理陷阱

### 陷阱1：分析瘫痪

**现象**：面对选择时过度思考，无法决定

**解决方案**：

- 限制信息量，不要让每个选择都需要深度分析
- 提供明确的倾向性提示
- 先检查信息与目标是否清楚；时间限制只在适合的挑战中使用，不拿倒计时代替解释

---

### 陷阱2：错失恐惧（FOMO）

**现象**：害怕错过其他选项的内容

**解决方案**：

- 设计让重玩有价值的结构
- 不同路径互补而非完全替代
- 提供"概览"让玩家了解其他可能

---

### 陷阱3：沉浸中断

**现象**：出戏的选择或后果破坏体验

**解决方案**：

- 选项必须符合角色设定
- 后果必须符合世界观逻辑
- 避免"元游戏"式的选择

## 反馈设计原则

### 即时反馈

**目的**：确认玩家的选择已被接收

**示例**：

```
你决定：直接揭穿他的谎言
（反馈）气氛瞬间凝固...
```

---

### 延迟反馈

**目的**：让玩家看到选择的长期影响

**示例**：

```
第一章的选择：帮助陌生人
第五章的反馈：原来他就是那个帮助过你的人
```

---

### 总结反馈

**目的**：在终点回顾整个旅程

**示例**：

```
因为你曾经的选择...
- 你选择了真诚，所以获得了信任
- 你选择了冒险，所以发现了真相
- 你选择了妥协，所以失去了尊严
```

---

## 设计检查清单

### 代理感检查

- [ ] 重要行动兑现相应承诺，局部表达不伪称改变结局
- [ ] 后果在合理时间内呈现
- [ ] 玩家能够预测大致影响

### 公平性检查

- [ ] 关键信息提前提供
- [ ] 隐藏风险有线索提示
- [ ] 选项和后果逻辑一致

### 满足感检查

- [ ] 每个结局都有价值
- [ ] 失败也有意义
- [ ] 重玩有新发现

### 流畅性检查

- [ ] 选择数量适合任务，非选择型互动按其操作负担判断
- [ ] 选项文本清晰
- [ ] 避免分析瘫痪

---

## 玩家类型适配

### 成就型玩家

- 提供收集要素
- 设计隐藏结局
- 显示完成度

### 探索型玩家

- 多种路径设计
- 隐藏内容丰富
- 奖励好奇心

### 故事型玩家

- 注重叙事质量
- 情感体验优先
- 角色深度塑造

### 挑战型玩家

- 困难选项
- 需要思考的谜题
- 高风险高回报
