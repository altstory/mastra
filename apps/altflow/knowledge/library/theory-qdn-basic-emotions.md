一句话定义：每种基础情绪是 Q、D、N 三个变量高低的一种组合，共 8 种；写作时先定目标情绪，再按公式取事件扳机合成情节。

## 适用问题
- 想制造某种明确的情绪（狂喜、暴怒、恐惧等）却写不出效果。
- 同类情绪（乐/怡、惧/惊）区分不清。

## 方法
### 公式总表
| 情绪 | 公式 | 一句话心理 |
|---|---|---|
| 乐（狂喜） | +Q +D +N | 我超牛，好事砸头，而且出乎意料 |
| 悲（沉痛） | -Q -D -N | 无力，珍视的永远失去，且在预料之中 |
| 怒（暴怒） | -Q +D +N | 被羞辱，必须报复，且来得突然 |
| 惧（恐惧） | -Q -D +N | 要死了，更糟的在后面，怪物突然出现 |
| 惊（震惊，中性） | +Q -D +N | 状态尚可、无特别期待，却被刷新认知 |
| 怡（惬意） | +Q +D -N | 自信、好事将至且应得，一切在计划内 |
| 怯（胆怯/自卑） | -Q +D -N | 好东西在招手，但觉得自己配不上、怕有诈 |
| 安心 | +Q -D -N | 风波过后，安全、平静，无特别期待 |

### 合成步骤
1. 定义目标：要的是哪一档（如“狂喜”而非“开心”）。
2. 拆解化学式：用上表。
3. 取扳机：按 QDN 事件库逐项配齐；同一场景里三项扳机要全部落地，少一项情绪就不纯。

### 各配方的扳机思路
- 乐：+N 意外（众人嘲笑时随手刮开彩票）；+D 巨大奖励（中头奖）；+Q 被尊重与掌控（当众求婚，震惊全场）。
- 悲：-N 符合预期的坏结果（病重爱人如医生预言般平稳衰退）；-D 希望彻底破灭（握着冰冷的手，知道不会再有奇迹）；-Q 彻底失败失控（心电图拉成直线，感到被世界抛弃）。
- 怒：+N 与 -Q 来自突然强烈的价值打击（众目睽睽被无征兆打耳光）；+D 来自强烈的反击欲望（不哭，抬头，心里涌起“我要你加倍奉还”）。
- 惧：+N 打破常规（空荡医院走廊背后的脚步声）；-Q 无力（腿像灌了铅）；-D 希望被剥夺（唯一出口自己关上）。
- 惊：+Q、-D 先维持常规（在家悠闲看电视）；+N 打破常规（穷同事开私人直升机悬停窗外）。
- 怡：-N 维持常规（考试成绩公布前）；+Q+D 自信与正向期待（学霸不对答案，淡定说“第一名应该还是我”）。
- 怯：+D 给希望（收到校花的舞会邀请）；-Q、-N 自卑加平静不安（看着旧衬衫和空钱包，觉得是恶作剧，迟迟不敢回复）。
- 安心：+Q 稳定、-D、-N（打败魔王后躺在老槐树下喝茶，看孩子追蝴蝶），适合大结局的“软着陆”。

## 示例
目标“暴怒”：配方 -Q +D +N。场景：宴会上被反派毫无征兆地打了一巴掌（+N、-Q），全场死寂中主角抬头对上对方轻蔑的眼神，涌起必须加倍奉还的渴望（+D）。

## 检查
- 三个变量是否都有对应事件？缺 +D 的“怒”会变成憋屈或悲。
- 惧和惊的区别：惧要 -Q -D，惊要 +Q -D；惊不危险，只刷新认知。
- 乐与怡的区别：乐有 +N 意外，怡是 -N 的从容。
