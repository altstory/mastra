# 创作知识库目录

目录名称与用途由 `directories.json` 管理，正文清单由 `manifest.json` 管理。目录显示中文，路径键保持稳定，已有 Agent 引用不变。

来源与核对记录集中保存在 `attribution/page-sources.md` 和 `RESEARCH-SOURCES.md`，不导入知识页正文；原始许可证保留在 `attribution/` 中。

## 分类

- **受众与案例研究**（`research`，5 篇，含子目录）：受众需求、观看动机、短剧案例与类型研究；人口标签仅作背景。
- **互动叙事与体验**（`method`，21 篇，含子目录）：选择、动作、探索、表达与协作的叙事设计，以及反馈、状态和分支结构。
- **动作、探索与系统互动**（`method/interaction`，12 篇，含子目录）：从玩家动词到操作反馈、解谜、照料、协作、可访问性和原型制作。
- **编剧方法与人物**（`craft`，26 篇，含子目录）：故事构思、人物、场景、对白、结构、改编与剧本审读。
- **故事开发与剧本改编**（`craft/screenwriting`，12 篇，含子目录）：从一句话故事到人物动机、单场戏、剧集结构、改编取舍和修改排序。
- **人物成长与主体性**（`craft/audience`，2 篇，含子目录）：女性主角、青春成长和身份探索中的具体目标、行动空间与处境。
- **情感关系与群像**（`craft/relationships`，3 篇，含子目录）：亲密关系、家庭代际、友情与共同任务中的相互影响。
- **职业与社会处境**（`craft/social`，1 篇，含子目录）：职业行动、现实生活、专业伦理与利益冲突。
- **悬疑、惊悚与日常叙事**（`craft/genre`，3 篇，含子目录）：证据与揭示、不确定性与控制感、低对抗叙事与告别。
- **类型创作指南**（`genre`，6 篇，含子目录）：复仇、言情、悬疑、历史、武侠与奇幻的类型参考，可组合使用。
- **语言与叙述风格**（`style`，5 篇，含子目录）：自然人声、网文、古风、文学与极简等可选表达方式。
- **创作档案模板**（`template`，4 篇，含子目录）：角色、世界、地点与人物语言档案的参考结构。
- **剧本写作案例**（`research/script-cases`，27 篇）：开场、冲突升级、钩子、对白、悬念等写法，每篇含观察、写法、原创例子和质检。
- **创作理论体系**（`theory`，130 篇，含 15 个子目录）：
  - `theory/audience`（5 篇）观众与梦境：观众需求、安全感、效率与真实感。
  - `theory/info-gap`（6 篇）信息差与爽感：信息差玩法、信息牌手法、金手指、爽感类型与四阶段配比。
  - `theory/pacing`（8 篇）预期、节奏与大纲：预期拉扯、期待循环、梗概检测、810 大纲与细纲。
  - `theory/drivers`（21 篇）驱动、人物与表达：三大驱动选型、人物魅力与小传八要素、台词动作画面。
  - `theory/archetypes`（13 篇）事件原型与大纲搭建：十类故事原型、十里程碑、从事件倒推主角。
  - `theory/emotion`（15 篇）情绪工程：求必得与求不得、QDN 模型、情绪合成、放大与阻断、钩子与震撼。
  - `theory/genre-design`（14 篇）悬疑、权谋、世界观与喜剧设计。
  - `theory/revisions`（3 篇）常见说法的修订：表达、信息差、情绪节奏、反派、预期、驱动与原型的更准确做法。
  - `theory/ai-collab`（4 篇）与 AI 协作写作：给 AI 建规则、分步写剧本、审读改稿、排查失控、人机分工。
  - `theory/supplement-emotion`（3 篇）情绪与爽感补遗：主情绪、情绪曲线设计、压抑与爽感。
  - `theory/supplement-expectation`（5 篇）预期、节奏、信息差与钩子补遗。
  - `theory/supplement-character`（11 篇）人物写法补遗：可信度、转变、魅力、两难、配角与强人物。
  - `theory/supplement-event`（9 篇）事件、类型与世界观补遗：事件设计、悬疑权谋、世界观、喜剧、恐惧与原型。
  - `theory/supplement-craft`（5 篇）表达与成长补遗：动作台词场景的设计时机、文字与画面、阅历与成长。
  - `theory/qa`（8 篇）创作答疑：常见问题的简短结论与自检方法。

另有「中文创作指南」「工作区使用说明」两篇运行时入口文档，保留在根目录。

## 导入

在应用目录运行 `node --import tsx scripts/import-library.mjs`，先同步目录名称，再幂等导入正文。
只更新目录时加 `--directories-only`，不会覆盖知识正文。用 `ALTFLOW_RUNTIME_ROOT` 指定运行库目录。

目录名称更新使用 Knowledge 公共写入接口，保留目录 ID、路径、正文和子页面。不要通过改写数据库 parentId 或删除重建目录来改名。
