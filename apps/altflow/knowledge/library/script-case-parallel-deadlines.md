# 用共享时限串起平行行动

## 参考与观察

该剧本在车辆行进、旅馆楼梯和雪地接近目标之间切换。音乐在不同层出现，角色的反应让读者知道上层的时机已开始影响下层。

## 写法

在切线前写清每处的人正在做什么。选择能在各线被不同人物察觉的信号，并给每条线一个可以独立说清的失败代价。读者回来时应能从场景标题和动作认出原来的任务。

## 原创例子

山火转向时，高处的消防员必须接通蓄水池，山脚驾驶员必须驶过仅剩的便桥，两处都听到最后一次撤离广播。阀门迟开会让桥面失去水幕，车辆迟到会堵住消防通道。

## 质检

逐线摘读，每条线是否都有自己的任务和失败代价？交叉读时，上一条线的变化是否会影响下一条？
