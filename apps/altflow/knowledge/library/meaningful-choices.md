# 有意义的选择（Meaningful Choices）

## 概述

互动叙事的核心是"有意义的选择"——玩家的选择必须能够实质性地影响故事走向或体验，而非仅仅是表面差异。

---

## 选择的三个层次

### 层次1：表面差异（Cosmetic）

**定义**：选择只影响后续的文本描述，不影响实际内容

**示例**：
```
选项：
A. 红色衣服 → "你穿着红色衣服..."
B. 蓝色衣服 → "你穿着蓝色衣服..."
（后续完全相同）
```

**评估**：
- 有助于代入感
- 但不应该是唯一类型
- 可在次要选择中使用

---

### 层次2：内容差异（Content）

**定义**：选择导向不同的内容节点，有不同的叙事体验

**示例**：
```
选项：
A. 直接询问 → N002（对方拒绝，需要另想办法）
B. 委婉试探 → N003（对方透露信息，建立信任）
（后续内容不同）
```

**评估**：
- 互动叙事的核心
- 应该占大多数选择
- 让玩家感受到"选择很重要"

---

### 层次3：结构差异（Structural）

**定义**：选择影响整个故事结构和解锁条件

**示例**：
```
选项：
A. 加入阵营A → 解锁路线A，影响结局类型
B. 加入阵营B → 解锁路线B，影响结局类型
C. 保持中立 → 解锁路线C，特殊结局
```

**评估**：
- 最有影响力的选择
- 应该谨慎使用
- 明确告知玩家重要性

---

## 好选择的标准

### 标准1：可理解性

**玩家能理解选项的含义**

**好的示例**：
```
A. 直接对质 → 他可能会生气，但能直接得到答案
B. 暗中调查 → 更安全，但可能错过关键信息
```

**糟糕的示例**：
```
A. 选择这个 → 你不知道会发生什么
B. 或选那个 → 同样不知道
```

---

### 标准2：有意义性

**选择有实际影响**

**好的示例**：
```
A. 帮助她 → SV_affection += 10, 解锁后续路线
B. 拒绝她 → SV_affection -= 10, 开启不同路线
```

**糟糕的示例**：
```
A. 温柔地问 → N002
B. 严厉地问 → N002（相同目标，无差异）
```

---

### 标准3：平衡性

**各选项都有其合理性**

**好的示例**：
```
A. 优先效率 → 完成任务，但可能损害关系
B. 优先关系 → 建立信任，但任务可能失败
C. 寻求平衡 → 折中方案，需要技巧
（各有优劣，无绝对最优）
```

**糟糕的示例**：
```
A. 完美方案 → 无代价，全收益
B. 糟糕方案 → 有代价，无收益
（显然只有A合理）
```

---

### 标准4：后果可见性

**玩家能预期大致后果**

**好的示例**：
```
A. 【需要SV_confidence > 50】直接挑战
   高风险高回报

B. 【任何人可选】谨慎准备
   低风险低回报

C. 【需要特殊物品】利用道具
   需要前期准备
```

**糟糕的示例**：
```
A. 做某事 → 不知道会发生什么
B. 做另一事 → 同样不知道
```

---

## 选项设计原则

### 原则1：简洁性

**选项文本≤20字**

**好的示例**：
```
A. 直接上前揭穿
B. 继续观察等待
C. 悄悄提示委托人
```

**糟糕的示例**：
```
A. 你决定直接走上前去，当着所有人的面揭穿他的谎言
B. 你觉得应该继续观察，等收集到更多信息再行动
C. 你选择悄悄地给委托人一个提示，让他自己处理
```

---

### 原则2：明确性

**选项传达明确的意图**

**好的示例**：
```
A. 相信她的话
B. 怀疑她的动机
C. 保留判断
```

**糟糕的示例**：
```
A. 嗯...
B. 那个...
C. 还是...
```

---

### 原则3：独特性

**每个选项代表不同的方向**

**好的示例**：
```
A. 理性分析（注重逻辑）
B. 感性体验（注重感受）
C. 道德判断（注重原则）
```

**糟糕的示例**：
```
A. 比较同意
B. 有点同意
C. 也同意
（都是同意，只是程度不同）
```

---

### 原则4：公平性

**所有选项都应该可达成**

**好的示例**：
```
A. 【SV_confidence > 30】大胆行动
B. 【任何人可选】谨慎行动
C. 【有相关线索】智取
（条件明确，玩家可规划）
```

**糟糕的示例**：
```
A. 【SV_某未知属性 > 90】特殊选项
B. 普通选项
（玩家不知道如何满足A的条件）
```

## 常见问题

### 问题1：虚假选择

**表现**：多个选项导向相同结果

**检测**：
```javascript
// 检查是否有相同的目标节点
if (choiceA.target === choiceB.target) {
  // 可能是虚假选择
}
```

**解决**：
- 合并为单一选项
- 或设计差异化后果
- 或使用条件文本体现差异

---

### 问题2：明显最优

**表现**：某个选项明显优于其他

**示例**：
```
A. 完美方案：成功+奖励+无代价
B. 普通方案：成功+小奖励
C. 糟糕方案：可能失败
（玩家只会选A）
```

**解决**：
- 每个选项都有代价
- 每个选项都有收益
- 风险与收益平衡

---

### 问题3：选择过多

**表现**：4个以上选项让玩家分析瘫痪

**示例**：
```
请选择你的行动：
A. 直接上前
B. 悄悄接近
C. 远程观察
D. 寻求帮助
E. 设下陷阱
F. 撤退离开
G. 询问同伴
H. 等待时机
（太多选项，玩家难以决策）
```

**解决**：
- 限制在2-3个主要选项
- 将次要选项合并
- 分层次决策

## 选择设计工作流

### 步骤1：确定选择点

**这个节点需要选择吗？**
- 如果是关键转折点 → 需要
- 如果是普通推进 → 可能不需要
- 如果是结局判定 → 需要

### 步骤2：确定选项类型

**是什么类型的选择？**
- 方式选择（如何做）
- 优先级选择（先做什麼）
- 价值选择（什么更重要）
- 信息选择（相信什么）

### 步骤3：设计选项

**每个选项应该：**
- 有明确的意图
- 有不同的后果
- 有其合理性
- 有代价和收益

### 步骤4：验证

**检查：**
- 选项文本≤20字 ✓
- 各选项独特 ✓
- 后果可预期 ✓
- 无明显最优 ✓
- 条件明确 ✓

## 选择的情感维度

### 情感投入

让选择与玩家情感相关：

```
A. 保护她（即使自己受伤）
B. 保护自己（即使她受伤）
C. 寻找第三条路
（涉及价值观和情感）
```

### 后果承载

让选择的后果有情感重量：

```
A. 选择会伤害某人
   → 后续内容承载这份愧疚
B. 选择会牺牲自己
   → 后续内容承载这份代价
```

### 长期影响

让选择的影响持续存在：

```
第一章的选择：
A. 帮助角色X
→ 第三章：角色X回来帮助你
→ 第七章：角色X为你牺牲
→ 结局：解锁角色X相关结局
```
