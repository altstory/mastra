# 互动叙事体验平衡指南

## 概述

检查各主要路径的内容深度和体验质量是否平衡，避免某条路径明显优于或劣于其他路径。

---

## 平衡维度

### 1. 路径长度平衡

**指标**：各路径的节点数

**评估标准**：
- ✅ 优秀：差异≤20%
- ⚠️ 可接受：差异20%-30%
- ❌ 不平衡：差异>30%

**不平衡示例**：
```
PATH_A: 10个节点, 20000字
PATH_B: 5个节点, 10000字
PATH_C: 15个节点, 30000字

差异：PATH_C是PATH_B的3倍 → ❌ 严重不平衡
```

**修复方案**：
1. 延长短路径：添加中间节点，深化体验
2. 压缩长路径：合并冗余节点，精简内容
3. 明确标注：如果短路径是"捷径"，明确告知玩家

---

### 2. 内容深度平衡

**指标**：内容的丰富度和质量

**检查维度**：

#### 2.1 描述密度
- 描述性文字占比应>30%
- 避免过度对话导致画面感缺失

#### 2.2 选择密度
- 选择节点占比应>30%
- 避免长段落无交互

#### 2.3 情感弧线
- 每条路径应有完整的情感发展
- 避免某些路径情感单薄

---

### 3. 难度平衡

**指标**：达成各路径的难度

**难度评估**：
```
简单 (SV > 30): 无额外要求
中等 (SV > 50 + FLAG): 需要特定行为
困难 (SV > 70 + 物品): 需要精心规划
```

**问题表现**：
```
PATH_A: SV > 30（容易）
PATH_B: SV > 70（困难）
PATH_C: 需要特定物品（极难）
```

**影响**：
- 简单路径可能成为"默认选择"
- 困难路径可能无人体验
- 隐藏内容成本浪费

**修复方案**：
1. 调整难度：使各路径难度相近
2. 明确标识：告知玩家难度差异
3. 差异化奖励：困难路径有独特价值

---

### 4. 奖励平衡

**指标**：各路径结局的价值感

**价值评估要素**：
- 内容质量（字数、情感冲击）
- 独特性（是否有独特内容）
- 解锁价值（是否解锁新内容）

**问题表现**：
```
END_GOOD: 3000字，情感深刻
END_BAD: 500字，草草了事
```

**影响**：
- 玩家避开"坏"结局
- 降低重玩价值
- 浪费创作资源

**修复方案**：
1. 充实所有结局：每个结局都有价值
2. 差异化体验：而非"好"与"坏"的质量差异
3. 失败也有意义：坏结局也应给予启发

---

## 平衡调整策略

### 策略1：纺锤形平衡

在收束点之前确保各路径长度相近：

```
设计：
PATH_A: START → ... → CP01 (5节点)
PATH_B: START → ... → CP01 (5节点)
PATH_C: START → ... → CP01 (5节点)

CP01 → ... → END (3节点，共享)
```

---

### 策略2：条件差异化

在不同路径中使用相同节点但提供差异化体验：

```markdown
## N010（收束点）
{if path_from == "PATH_A"}
你从A路径而来，带着...
{else}
你从B路径而来，带着...
{endif}

无论如何，现在你需要...
```

---

### 策略3：内容复用

共享内容但不完全相同：

```
共享场景描述（50%）
+ 路径特定对话（30%）
+ 路径特定内心独白（20%）
= 独特体验但控制成本
```

---

### 策略4：难度补偿

为困难路径提供独特奖励：

```
困难路径：
- 解锁条件: SV > 70 + 特定FLAG
- 独特内容: 隐藏剧情 + 真结局
- 奖励: 更深刻的理解和独特CG

简单路径：
- 解锁条件: 无
- 普通内容: 标准剧情
- 奖励: 基础体验
```

---

## 平衡原则

### DO（应该做）

✅ 各路径长度相当（差异≤30%）
✅ 各路径有独特价值
✅ 难度与奖励匹配
✅ 所有结局都有意义
✅ 平等的创作投入

### DON'T（不应该做）

❌ 明显的"最优解"路径
❌ "垃圾"路径（无价值）
❌ 困难路径无额外奖励
❌ 坏结局草草了事
❌ 某路径明显被忽视

---

## 平衡的艺术

### 绝对平衡 vs 相对平衡

**绝对平衡**：所有指标完全相同
- 不现实
- 不必要
- 可能失去多样性

**相对平衡**：各指标在可接受范围内
- 现实可行
- 保持多样性
- 允许特色差异

### 平衡 vs 特色

**追求平衡 ≠ 消除差异**

不同路径可以有：
- 不同的长度（在30%差异内）
- 不同的风格（简洁 vs 详实）
- 不同的难度（简单 vs 困难）
- 不同的体验（理性 vs 感性）

关键是：
- 让每条路径都有价值
- 让每条路径都有玩家
- 让每条路径都值得体验

---

## 平衡验证流程

### 1. 数据收集

收集各路径的：
- 节点数和字数
- 选择密度
- 难度要求
- 结局价值

### 2. 差异分析

计算各指标的方差，识别超出阈值的问题

### 3. 生成报告

```markdown
## 体验平衡检查报告

### 总体评估
⚠️ 存在轻微不平衡

### 详细分析

#### 路径长度
- PATH_A: 10节点 (20000字)
- PATH_B: 7节点 (14000字)
- PATH_C: 12节点 (24000字)
- **评估**: ⚠️ 差异30%，可接受

#### 内容深度
- PATH_A: 描述充分，对话丰富
- PATH_B: 描述偏少，但情感深刻
- PATH_C: 描述丰富，但对话简练
- **评估**: ✅ 各有特色，平衡

#### 难度
- PATH_A: 容易 (SV > 30)
- PATH_B: 中等 (SV > 50 + FLAG)
- PATH_C: 困难 (SV > 70 + 特定物品)
- **评估**: ⚠️ 难度跨度大

#### 结局价值
- END_GOOD: 价值高 (3000字，深刻)
- END_BAD: 价值中 (1500字，有意义)
- END_TRUE: 价值极高 (5000字，独特)
- **评估**: ✅ 差异化良好

### 建议调整

1. **延长PATH_B**
   - 添加2-3个节点
   - 补充角色互动
   - 预计增加3000字

2. **降低PATH_C难度**
   - SV要求从70降至60
   - 增加获得物品的线索
   - 降低门槛提高可达性
```
