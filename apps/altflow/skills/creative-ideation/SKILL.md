# 创意构思

从已有想法和用户目标开始，核心体验可以在试写中逐步发现；没有先前文档或独立技能也能推进。人物、关系、生活片段、空间与玩家动作都可以是入口。

## 高概念

需要提案或快速比较时，用一两句话说清故事核心，可参考 **[主角] + [目标或情境] + [阻力或独特关系]**。日常、群像或探索作品也可从情境、关系与行动组织，不为了套公式硬造反派。

写好高概念的检查：

- 不看其他说明，只读这一句，能否知道谁、要什么、被什么阻挡？
- 独特性是否真的区别于同类作品，而不是换了设定的同一个故事？
- 是否与已定的核心体验一致？一致才保留，否则先改核心体验或改高概念，并告诉用户为什么。

## 类型与方法选型

《救猫咪》只是可选框架。也可从人物欲望、关系变化、情境、类型承诺或玩家行动定位方向；可混合类型，不强制把作品归入单一类别。选用框架时用来：

- 判断观众对这类故事的期待（哪些必须有，哪些可以打破）；
- 找到可对标的同类作品，作为类似作品参考。

只引用类型框架的要点，不要摘抄书中原文。

## 渐进展开

不要要求用户一次想清楚。按用户给的信息量决定先做到哪一级，做完告诉他怎么展开到下一级：

| 级别     | 内容                                                                  | 什么时候用       |
| -------- | --------------------------------------------------------------------- | ---------------- |
| 一句话   | 简短的核心创意，加主角、困境、目标、代价四个要素                      | 只有灵感时       |
| 一段话   | 100 到 200 字概要，含主角、冲突、目标、障碍，以及起点、中点、终点方向 | 想验证值不值得写 |
| 一页纸   | 概要、主要角色、适合的结构、代表场景、目标受众                        | 准备开始写       |
| 完整规格 | 以上全部，加成功标准、约束条件、风险，以及标出的待澄清点              | 正式创作前       |

信息量不决定级别，想清楚的程度才决定：用户一句话说得很具体，也可以直接跳到更高一级；写得很长但互相矛盾，要退回低一级先理清。这些篇幅与数量是沟通尺度，不是创作指标；可以跳级、删减或直接试写。

## 知识库参考

确定类型后，用知识库检索对应的题材页面：「复仇爽文创作知识」「言情创作知识」「悬疑推理创作知识」「历史题材创作知识」「武侠创作知识」「奇幻创作知识」，以及「短剧类型第一性原理分析」，了解局部题材惯例。同时按需检索女性主体性、家庭与代际、职业、友情与群像、成长、悬疑调查、恐怖、温柔日常和互动行动的新资料；受众由具体需求验证，不用男频女频标签决定人物或机制。

选驱动和定看点时，再检索：「三大故事驱动：人物、事件、情绪」 「驱动选型与主辅搭配」 「观众三类梦境订单（掌控者/关系者/逃避者）」 「事件驱动与十大故事原型总览」。

补充：「一条主情绪到底：统一情绪、核心梗与取舍」 「常见说法的修订（三）：预期、驱动与故事原型」。

## 工作步骤

1. 读取已有想法与材料，信息足够就推进，不要求用户重讲。
2. 需要比较方向时给出少量有实质区别的方案；方向已明确可直接细化或试写，各自说明侧重和取舍。用 ask_user.preview 的 directions 展示具体故事方案并询问差异最大的取舍；已选核心体验不等于已选具体故事。
3. 用户选定后，给出类型定位，并说明依据。
4. 有帮助时选少量类似作品作参考，说明相似点和差异点；不确定的作品信息标为「待核实」，不要编造。
5. 汇总进《创意构思文档》。扩展时出现影响人物或结局的新取舍，先展示精简版本讨论，不能把所有后续设计默认为已确认。

## 产出

- 核心创意或代表场景（需要提案时可用高概念）
- 类型定位及依据
- 类似作品参考
