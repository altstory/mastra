# 目标受众分析

受众分析要**围绕核心体验展开**：核心用户是「最需要这个核心体验的人群」，而不是人数最多的人群。

## 用户分层

| 层         | 含义                                           |
| ---------- | ---------------------------------------------- |
| 核心用户   | 最需要这个核心体验的人，产品为他们优先设计     |
| 次核心用户 | 会被吸引，但对体验的需求弱于核心用户           |
| 范围用户   | 可能接触到作品的更广人群，不为他们牺牲核心体验 |

## 吸引因素、流失原因与可调整条件

按具体作品和场景判断，不把用户固定成朋友或敌人：

- 哪些内容与动作吸引他，依据是什么；
- 哪些理解、时间、操作或内容门槛导致流失，是否能调整；
- 哪些偏好确实不适配本项目，可明确取舍，不贬低用户。

同一个人可同时喜欢多种体验。男频、女频、年龄等是背景或营销标签，不直接决定理性、情感、恋爱、竞争或动作偏好。

## Persona

需要帮助团队决策时，为实际有区别的需求群体写 Persona，包含：基本情况、使用场景、想从作品得到什么、会因什么放弃。写的是推测时，标注为「假设」，不要当成事实。

## 工作步骤

1. 先读已有用户信息，不足时围绕会改变创作的事项询问；共享知识库只作 Agent 内部参考，不向普通用户披露资料标题、目录、原文或可还原的内容。需要对外依据时使用可公开核实的外部来源，并说明其统计范围。
2. 按观看动机、使用场景与参与意愿提出需求分群；已有证据充分时再确定服务优先级，不必填满三层。
3. 分析吸引因素、流失原因和可调整条件。
4. 写 Persona。
5. 检查：每个用户层对应的设计取舍是否与核心体验一致。

## 产出

- 有助于当前决策的需求分群、场景与证据；Persona 按需提供
- 吸引、流失、可调整条件与项目取舍
- 已验证结论、样本边界与待验证假设；未实际研究或试玩时不声称验证完成。

按需检索「受众研究：从男频女频标签到观看需求」以及家庭、女性主体性、群像、成长、职业与互动可访问性资料，不能把单一题材报告外推为所有受众的需求。
