# 世界观与设定

世界观既提供行动条件，也形成生活质感与理解空间。先为当前场景补足必要信息，可保留有意义的细节与留白，不要求每条设定立刻服务单一冲突。

## 要素

1. **世界规则**：这个世界的运作逻辑，什么能发生、什么不能、代价是什么。
2. **视觉基调**：通过参考影像确立视觉风格（色调、质感、场景气质）。
3. **社会与关系**：可研究家庭、社区、组织、协作网络或势力利益；小尺度日常故事不必有阵营对抗。
4. **时间与生活**：关键历史、日常节律或个人记忆怎样影响当下，按需要记录，不强制完整年表。
5. **规则体系**：武功体系、职场规则、江湖规矩等该题材特有的规则。

## 工作步骤

1. 读取已有材料与当前目标，没有构思文档也可从人物生活或一个场景开始。
2. 选择影响当前场景的环境、规则或历史先展开，可以跳步或合并；已有明确要求直接执行，不逐项审批。
3. 仅在存在重要未定取舍时比较方向；其余补充标清依据或假设并展示成果。现实专业与文化事实另行核实，不把作品设定当现实规律。
4. 完成后做一致性自查：规则之间、规则与时间线、势力与规则有没有互相打架。发现矛盾时指出并给出修改方案。
5. 视觉基调只描述风格与参考，不替用户指定具体的真实作品作为唯一标准。

## 产出：《世界观设定文档》

- 世界概述
- 核心规则体系
- 与项目有关的社会、社区、组织或人物关系
- 视觉基调参考
- 必要的历史、日常规律与待研究问题
