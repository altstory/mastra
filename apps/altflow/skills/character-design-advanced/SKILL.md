# 高级人物设计

人物参与作品体验，也有自己的欲望、生活与关系；主要角色不只承担推动主角的工具功能。先理解已有材料，再按当前场景补足需要的信息。

## 核心概念

- **角色弧光**：角色从开始到结束的内在变化。
- **核心欲望**：角色最深层想要什么（不一定是他嘴上说的）。
- **核心恐惧**：角色最害怕什么。
- **内在冲突**：欲望与恐惧之间的拉扯，是人物最有戏的地方。

## Michael Hauge 六阶段

Setup → New Situation → Progress → Complications → Greater Crisis → Climax。
这是可选诊断框架，不是人物必须经历的路线。也可按关系、行动、认知或情境变化组织人物；坚守原有信念、失败或未彻底改变都能成立。引用要点，不抄原文。

## 人物系统口径

- **阻力来源**：可来自对手、制度、环境、关系、信息差或人物自身；有升级型对抗时才安排层级，不为日常、群像或照料故事硬造终极反派。
- **变化路径**：触发、抗拒、试探、接受是成长的一种参考，可省略、回退或改用其他组织方式，不按阶段补剧情。
- **对话辨识度**：通过立场、知识、表达习惯和情境区别人物，允许熟人说话相近；不要给每人硬塞口头禅或要求每句都能盲猜身份。
- **情绪与行动**：关键节点可以表达好奇、羞耻、温柔、归属、失落、责任或其他体验；爽点只是部分作品的方法，不给所有人物套打脸与反转。

## 工作步骤

1. 读取已有构思、场景和设定，只补当前设计所需信息，不要求全套前置文档。
2. 先设计主角：核心欲望、核心恐惧、内在冲突、弧光。
3. 为其他主要人物写独立目标、处境与相互影响；推动、对照、阻碍等功能只是辅助检查。
4. 画出关系图谱：情感关系与利益关系分开标注。
5. 为主要角色写人物小传（背景、性格、经历）和 2 到 3 句关键台词示例，台词要能体现人物的说话方式。
6. 自查：行动是否可追溯到处境与信息？主要人物是否影响局面？变化或坚守是否得到呈现？不强制欲望与恐惧必须对立。
